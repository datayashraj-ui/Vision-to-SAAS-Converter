<task type="auto">
  <name>Task 1: Initialize Vite + React + TypeScript project</name>
  <files>package.json, vite.config.ts, tsconfig.json, index.html, src/main.tsx, src/App.tsx</files>
  <action>
Run `npm create vite@latest . -- --template react-ts` to scaffold React + TypeScript with Vite.
Install dependencies with `npm install`.
Verify the base setup works with `npm run dev`.
Clean up default Vite template files (remove App.css boilerplate, default counter logic).
Configure vite.config.ts with proper server settings (port 3000, open browser).
Configure tsconfig.json with strict mode enabled for production-grade type safety.
  </action>
  <verify>npm run dev starts development server without errors</verify>
  <done>Development server runs on localhost:3000, TypeScript compiles without errors, base React app renders</done>
</task>

<task type="auto">
  <name>Task 2: Install and configure Tailwind CSS</name>
  <files>tailwind.config.js, postcss.config.js, src/index.css</files>
  <action>
Install Tailwind CSS: `npm install -D tailwindcss postcss autoprefixer`
Initialize Tailwind: `npx tailwindcss init -p`
Configure tailwind.config.js with content paths: `content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"]`
Add Tailwind directives to src/index.css:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```
Test Tailwind by adding a utility class to verify it works.
Reason for Tailwind: Rapid UI development, consistent design system, production-ready optimization.
  </action>
  <verify>Tailwind utility classes render correctly in browser</verify>
  <done>Tailwind CSS configured, utility classes working, no styling errors</done>
</task>
